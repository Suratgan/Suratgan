궁중 수라간 프론트 로비

전통 궁중의 품격을 현대적인 주문 경험으로 재해석한 서비스입니다. 아래 화면으로 이동해 이메일 인증, 회원가입, 로그인, 주문 및 리뷰 기능을 테스트할 수 있습니다.

서비스 이동

발표 흐름에 맞게 단계별 화면으로 진입할 수 있습니다.

발표용 데모

1. 이메일 인증

인증 코드를 요청하고 이메일 인증을 완료하는 첫 단계입니다.

2. 회원가입

사용자 정보를 입력하고 고객 또는 점주 권한으로 가입합니다.

3. 로그인

로그인 후 JWT 기반 인증 흐름과 실제 앱 화면 진입을 테스트합니다.

4. 주문 / 리뷰 화면

카테고리 조회, 주문 생성, 주문 상태 변경, 리뷰 작성까지 확인합니다.

5. 결제 테스트

테스트 결제 버튼을 통해 결제 연동 흐름을 별도로 확인할 수 있습니다.

발표 추천 동선

Step 1 이메일 인증 요청 및 인증 완료
Step 2 회원가입으로 계정 생성
Step 3 로그인 후 토큰 저장 및 앱 화면 진입
Step 4 주문 생성, 주문 조회, 리뷰 작성, 결제 테스트까지 시연

기능 링크 구조는 기존 파일과 동일하게 유지했습니다.
